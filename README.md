# todo-task-tracker
A simple console-based To-Do application in Python

📝 To-Do Task Tracker App

A beginner-friendly console application for tracking and managing daily tasks. Built as a first real Python project by a junior developer.

🚀 Features

View, add, and delete tasks

Mark tasks as completed (✅)

View tasks scheduled for today

Automatically timestamp new tasks

Save and load tasks from file (tasks.txt)

Track completed task statistics (done_stats.txt)

💻 Technologies Used

Python

File handling (read/write)

Lists, loops, conditions, string methods

datetime module

f-strings and input formatting

📂 How to Run

python todo_list.py
